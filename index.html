🚦 Traffic Lights

Learn the three traffic light colours.

RED = STOP

Red means you must stop.

Kırmızı = Durmalısın.

AMBER = STOP IF SAFE

Stop if you can do so safely.

Sarı = Güvenliyse dur.

GREEN = GO IF CLEAR

Go only if the road is clear.

Yeşil = Yol açıksa ilerle.

🧠 MEMORY TRICK – HAFIZA KODU
🔴 RED → STOP → DUR
🟡 AMBER → STOP IF SAFE → GÜVENLİYSE DUR
🟢 GREEN → GO IF CLEAR → YOL AÇIKSA İLERLE
